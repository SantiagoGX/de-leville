# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

A custom Shopify 2.0 theme for **De Leville**, a luxury leather goods brand. Built on the Shopify "Skeleton" starter theme (v0.1.0). No build system — pure Liquid, CSS, and vanilla JavaScript.

## Development Commands

This theme has no `package.json` or build process. Development is done via Shopify CLI:

```bash
shopify theme dev                  # Start local dev server (hot reload)
shopify theme push                 # Push theme to Shopify store
shopify theme pull                 # Pull latest theme from store
shopify theme check                # Lint Liquid files
```

There are no automated tests. Changes are verified through the Shopify theme editor and live preview.

## Architecture

### Shopify 2.0 Section-Based Architecture

- **`sections/`** — 49 Liquid files, each a self-contained UI component with its own schema (settings, blocks, presets). Custom sections are prefixed with `snc-`.
- **`templates/`** — JSON files that declare which sections appear on each page type and in what order. Most are auto-generated by the Shopify editor — avoid manual edits to `product.json` and `index.json`.
- **`snippets/`** — Reusable partials included via `{% render %}`. Not independently configurable — they receive data via parameters.
- **`layout/theme.liquid`** — The root HTML shell. Includes critical CSS inline and loads `snc-sections.js`.
- **`blocks/`** — Generic block types (`text.liquid`, `group.liquid`) reusable across sections.

### JavaScript (`assets/snc-sections.js`)

Single 131KB bundled file. Uses a section registry pattern: each section type registers itself and handles its own lifecycle (init on page load, re-init on dynamic section add via Shopify's `document:shopify:section:load` event). Includes event listener cleanup to prevent memory leaks.

### CSS / Theming

- **`snippets/css-variables.liquid`** — Outputs `:root { }` CSS custom properties driven by theme settings (colors, fonts, spacing). All dynamic theming flows through this.
- **`assets/critical.css`** — Inlined in `<head>` via `theme.liquid` for above-the-fold performance.
- **`config/settings_schema.json`** — Defines all theme settings available in the Shopify customizer (fonts, colors, layout, product grid).
- **`config/settings_data.json`** — Current active values for those settings.

### Localization

Translations in `locales/`. `en.default.json` is the source of truth. `es.json` provides Spanish translations. Schema translations (section/setting labels in the editor) live in `en.default.schema.json`.

### Fonts

Custom Futura PT fonts (Bold, Book, Medium) stored as `.woff` files in `assets/`. Loaded via `@font-face` with `font-display: swap`. Fallback configured through the Shopify font picker in settings.

## Key Conventions

- All custom section/snippet files are prefixed with `snc-` to distinguish from base theme files.
- CSS custom properties (e.g. `--color-foreground`, `--font-body-family`) are the styling contract between settings and templates — change values in `css-variables.liquid`, not hardcoded in section files.
- Block schemas inside sections define the editor UI for that section's content — each `{% schema %}` block at the bottom of a section file is the source of truth for its settings.
- Button shape convention: all interactive buttons use `border-radius: 999px` (pill shape) — established across PDP and side cart. Apply this to any new button components.

## Arquitectura de Páginas de Colección — Decisión 2026-05-04

### Patrón adoptado: Separación Shop / Story

Cada colección (Classico, Incontro, Mezza Luna, Chains, Bags) opera con dos páginas distintas:

**1. Página de compra — `/collections/{handle}`**
- Template: `collection.{handle}.json` → sección `snc-plp`
- Grid 4 columnas full-bleed, tarjetas Home Showcase style
- Hero opcional (video/imagen, configurable por sección)
- CTA sutil "Discover the story →" debajo del título de colección (11px uppercase, texto underlined, configura URL en schema de snc-plp)
- Sin contenido editorial ni narrativo — foco 100% en conversión

**2. Página editorial — `/pages/{handle}`**  
- Template: `page.{handle}.json` → secciones editoriales existentes + `snc-home-showcase` (grid 4 cols) al final
- Contenido de marca: historia, craftsmanship, video campaign
- Grid de productos al pie para capturar conversión de usuarios descubridores
- Acceso desde el CTA de la página de compra

### Rationale de lujo
Mismo patrón que LV, Cartier, Bvlgari: la URL de colección es para comprar (grid limpio, sin fricción narrativa). La historia vive en editorial separado que profundiza el deseo. El comprador con intención llega al grid; el curioso llega a la historia y luego compra.

## snc-incontro-story — Arquitectura (2026-05-07/08)

### Descripción
Sección `sections/snc-incontro-story.liquid` (1100+ líneas). Reemplaza `snc-horizontal-slides` + `snc-scroll-video` en `templates/page.incontro.json` (ambas marcadas `disabled: true`). Prefix CSS/JS: `sis`.

### Desktop (≥990px) — 700vh total
- **Phase 1 (500vh)**: 3 columnas sticky — texto izq, video centro, botones der. Scroll-driven: PURO→SEGRETO→ESSENZA→REGALE en orden. Al llegar a REGALE: texto/botones fade+blur saliendo, video decelerates hasta pausar (playbackRate 1→0), video se centra en viewport con `getBoundingClientRect()` + `position:absolute` lerp, vignette `mask-image: radial-gradient` oval para ocultar bordes del contenedor.
- **Phase 2 (200vh)**: `d1El` background→transparent, `splitVid` sube a z-index 6. Ring congelado centrado: rise+fade+blur mientras split video (anillos separándose) fades in desde z-index 6. Blur dissolve blur peak en midpoint. Texto "THE STORY" aparece con blur-dissolve a los 45% de Phase 2.

### Mobile (<990px) — 560vh total
- **Phase 1 (400vh)**: 4 videos fullscreen sticky. `object-fit: contain`, 98% ancho, max-height 72vh. `preload="none"` en HTML; JS carga solo activo + siguiente (progressive). Videos seeked a 30% de duración al cargar (mid-spin). PlaybackRate NO se resetea a 0 al desactivar. Tab strip rediseñado: pills negros llenos para activo, fondo blanco con `border-top: 1px`, `env(safe-area-inset-bottom)` support.
- **Phase 2 (160vh)**: REGALE fades out → split video crossfade easeInOut 28%. Blur sobre `<video>` interno (no el wrapper) para evitar artifact de borde rectangular. Word-by-word stagger reveal del texto.

### Bugs críticos resueltos durante desarrollo
- `::after { z-index: 20 }` cubría tabs (z-index 10) con fondo blanco → texto invisible → corregido a z-index 3
- `.sis__vid { opacity: 0 }` hacía invisibles los mobile variant videos → `.sis__mob-wrap .sis__vid { opacity: 1 }` en mobile media query
- `easeOut3`/`easeInOut2` declaradas dentro de `if` block → movidas al IIFE scope
- `preload="auto"` en 4 videos simultáneos → progressive loading: solo activo + siguiente

### Template
`templates/page.incontro.json`: `snc_incontro_story` como primera sección activa. Bloques en orden PURO→SEGRETO→ESSENZA→REGALE. `split_video_url` apunta a CDN URL del video de anillos separándose.
